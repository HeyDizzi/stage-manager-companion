# stage-manager-companion

a lightweight companion for stage manager. raycast extension

Window layouts that leave the left edge of the screen free for the Stage Manager strip. No Raycast Pro needed.

## Commands

| Command | What it does |
| --- | --- |
| Maximize (Stage Manager) | Fills the screen to the right of the strip |
| Left Half (Stage Manager) | Left half of that space |
| Right Half (Stage Manager) | Right half of that space |

Bind them to hotkeys in Raycast Settings → Extensions → Stage Windows.

## Preferences

- **Stage Manager Strip Width**: pixels reserved on the left (default `180`)
- **Gap**: padding around and between windows (default `0`)

## Install / update

```sh
npm install
npm run dev   # installs into Raycast; Ctrl-C once it's ready, the extension stays installed
```

## How it works

Windows are read and moved with Raycast's `WindowManagement` API. The usable area of each screen (minus menu bar and Dock) comes from a small JXA/AppKit script. It's cached and only re-measured when the display setup changes, so change Dock settings and it won't notice until then.
